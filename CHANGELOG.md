## [0.1.0] - 2026-07-09

### Added

* `ssh-vm`:
    * Supports connecting to vmm(4) virtual machines (VMs) over ssh(1) by
        either name or numerical ID (as shown in vmctl(8))
    * Supports optional username specified as `[user@]virtualmachine`
